# 电商商品价格自动化采集与对比工具

一款支持京东、淘宝、拼多多三大主流电商平台的商品价格批量采集、清洗、对比与可视化分析工具。

## 目录结构

```
price-comparator/
├── core/                    # 核心模块
│   ├── models.py           # 数据模型定义（Product, ComparisonResult等）
│   ├── collector.py        # 采集调度器（多线程并发采集）
│   └── analyzer.py         # 数据分析器（清洗、排序、性价比计算）
├── collectors/              # 平台采集器
│   ├── base.py             # 采集器基类（抽象模板方法）
│   ├── jd.py               # 京东采集器
│   ├── taobao.py           # 淘宝采集器
│   └── pdd.py              # 拼多多采集器
├── utils/                   # 工具模块
│   ├── data_cleaner.py     # 数据清洗与去重
│   └── visualizer.py       # 数据可视化（Chart.js配置生成）
├── web/                     # Web演示
│   ├── app.py              # Flask后端
│   └── templates/index.html # 前端页面
├── examples/               # 示例数据
├── cli.py                   # 命令行工具入口
└── requirements.txt         # Python依赖
```

## 整体架构设计

### 架构模式

采用 **分层架构 + 策略模式 + 模板方法模式**：

```
┌─────────────────────────────────────────────────┐
│                  表现层 (Presentation)            │
│  ┌───────────┐          ┌──────────────────┐   │
│  │  CLI 工具  │          │  Flask Web 页面  │   │
│  └───────────┘          └──────────────────┘   │
├─────────────────────────────────────────────────┤
│                  核心层 (Core)                    │
│  ┌─────────────────┐  ┌────────────────────┐  │
│  │ CollectorManager │  │  ProductAnalyzer   │  │
│  │   采集调度器      │  │    分析对比器       │  │
│  └─────────────────┘  └────────────────────┘  │
├─────────────────────────────────────────────────┤
│                  采集层 (Collectors)              │
│  ┌──────────┐ ┌──────────┐ ┌────────────────┐  │
│  │ 京东采集器 │ │ 淘宝采集器 │ │  拼多多采集器    │  │
│  └──────────┘ └──────────┘ └────────────────┘  │
│  ┌──────────────────────────────────────────┐  │
│  │          BaseCollector (基类)              │  │
│  └──────────────────────────────────────────┘  │
├─────────────────────────────────────────────────┤
│                  工具层 (Utils)                   │
│  ┌──────────────┐  ┌────────────────────────┐  │
│  │ 数据清洗模块   │  │     数据可视化模块      │  │
│  └──────────────┘  └────────────────────────┘  │
└─────────────────────────────────────────────────┘
```

### 核心设计模式

1. **模板方法模式**：`BaseCollector` 定义采集流程骨架，子类实现具体平台逻辑
2. **策略模式**：各平台采集器可独立替换，通过 `CollectorManager` 统一调度
3. **工厂模式**：`CollectorManager` 根据平台名称实例化对应采集器
4. **数据类模式**：使用 Python `dataclass` 定义清晰的数据模型

## 数据获取核心逻辑

### 采集流程

```
输入关键词
    │
    ▼
CollectorManager 初始化
    │
    ├─► 京东采集器 (线程1) ──► 搜索页面请求 ──► HTML解析 ──► 商品列表
    ├─► 淘宝采集器 (线程2) ──► 搜索页面请求 ──► HTML解析 ──► 商品列表
    └─► 拼多多采集器 (线程3) ──► 搜索页面请求 ──► HTML解析 ──► 商品列表
    │
    ▼
汇总所有平台数据
    │
    ▼
数据清洗（去空值、格式化、标准化）
    │
    ▼
数据去重（标题相似度 + product_id 去重）
    │
    ▼
排序 + 分析 + 性价比评分
    │
    ▼
输出对比结果
```

### 关键技术点

1. **多线程并发采集**：使用 `ThreadPoolExecutor` 并行采集多个平台，提升效率
2. **模拟数据支持**：内置模拟数据生成器，便于开发演示和测试
3. **反爬防护设计**：
   - 随机延迟请求
   - User-Agent 轮换
   - 代理支持（预留接口）
4. **容错处理**：单平台采集失败不影响整体结果

### 采集字段

## 数据可视化方案

### 图表类型

1. **价格排行柱状图**（横向条形图）
   - 展示所有商品价格从低到高排列
   - 颜色区分不同平台
   - 快速定位最低价商品

2. **平台均价对比图**（柱状图）
   - 对比各平台平均价格
   - 辅助判断哪个平台整体更便宜

3. **价格区间对比图**（分组柱状图）
   - 展示各平台最低价与最高价
   - 直观显示价格分布范围

4. **价格-销量散点图**
   - X轴：价格，Y轴：销量
   - 分析价格与销量的相关性
   - 发现高性价比区域

5. **价格趋势折线图**（30天模拟）
   - 展示各平台近30天价格走势
   - 辅助判断购买时机

### 技术实现

- 前端使用 **Chart.js 4.x** 渲染图表
- 后端生成图表配置数据，前后端分离
- 支持响应式布局，自适应不同屏幕

## 性价比推荐算法

综合评分 = 价格得分 × 0.4 + 销量得分 × 0.3 + 评分得分 × 0.3

- **价格得分**：归一化处理，价格越低得分越高
- **销量得分**：销量越高得分越高（归一化）
- **评分得分**：店铺评分4.0以上线性计分


### 搜索商品

```bash
# 基础搜索（使用模拟数据）
python cli.py search "手机"

# 指定每平台采集数量
python cli.py search "耳机" -n 30

# 指定平台
python cli.py search "空调" --platforms 京东 淘宝

# 导出结果
python cli.py search "手表" -o result.json
```

## 扩展开发

### 添加新平台

1. 在 `collectors/` 目录下创建新的采集器类
2. 继承 `BaseCollector`
3. 实现 `_mock_search` 和 `_real_search` 方法
4. 在 `collectors/__init__.py` 中导出
5. 在 `core/collector.py` 的 `collector_map` 中注册

### 真实采集注意事项

- 淘宝和拼多多有较强的反爬机制
- 建议使用无头浏览器（Playwright/Selenium）配合代理IP
- 需处理登录验证、滑块验证码等
- 遵守各平台 `robots.txt` 规定
- 仅用于学习研究用途
